## 结论

**原型尚未完成用户提出的目标。值得保留的是可审计的“经验 → 预测 → 行动 →
反馈”闭环；不值得继续维护的是退役架构、没有行为作用的包装，以及没有预测
验证却被称为预测稳定的等级。** 本次已实施删除和边界简化，并在继续收尾时修复
动作接线依赖审计记录、历史结果混入预测输入这两个实际问题。按用户要求仅保留
本地修改，暂停 GitHub 提交。

“物理”在当前实现中指 TypeScript 数值模拟的分布式晶格；经验来自 Minecraft
或合成环境的公开观察与动作回执。它不是物理硬件实验。“类似人类”应作为待检验
的机制假说，而不是由模块名、能量函数或吸引域动画赋予的能力结论。

## 从目标反推最小必要条件

| 要实现的目标 | 不可省略的可观察条件 | 当前证据与判断 |
| --- | --- | --- |
| 经验驱动 | 对同一问题，增添或移除相关真实经验应改变预测和后续动作；查询不能反过来制造经验 | R1/R2/R2A 写入边界、消融和只读查询已有实现及测试，值得保留 |
| 自主探索 | 行动应取得有用的新证据，并改变以后对不确定问题的处理 | 当前联合场能选择基本动作；固定新奇压力、轮换与使用抑制不等于已证明会主动选择有信息价值的实验 |
| 持续学习 | 同一代理在连续经验中学新关系、修正错误，同时保留仍成立的旧能力 | 有在线写入、恢复与可选时间尺度机制；仓库未提供可独立复现的长期获得、遗忘和重新适应结果 |
| 目标执行 | 只给终态目标，使用当前可用证据产生动作，失败后重新观察，最终由环境确认 | 仓库记录支持一次直接目标交互；最新三步任务只到 `0→1→2`，第三步无有效预测样本 |
| 物理机制有必要 | 在相同经验、感知和动作预算下，保留该机制应优于更小的可解释基线 | “物理机制不可替代”尚未得到这种对照实验支持，不能从实现存在推导 |

经验、行动、目标评价和未知状态是必要的。恰好三层介质、三维晶格、固定竞争场、
24 个预测种子、8 次事件/4 个场景门槛，都属于具体设计选择，无法单凭第一性原理
推导为必需。

## 被挑战的假设与实际处理

| 发现 | 为什么不成立或不必要 | 本次处理 |
| --- | --- | --- |
| 两代旧的点/页式记忆与当前分布式记忆并存 | 当前生产、G5/G6 路径不导入它们；旧实验不能认证当前模型，却一直参与编译和维护 | 删除旧 `PhysicalMemory`、`HierarchicalPhysicalMemoryV1`、专属学习器、预测器和运行器；由原提交保存历史 |
| 为旧测试替身提供第二种关闭保存协议 | 生产 Worker 根本不产生 `retired-snapshot-bundle`；运行时为测试而扩展职责 | 删除该 DTO、写入分支、旧格式保存函数和旧 receipt 的伪零新奇度回退；关闭测试直接使用真实 Worker |
| `meta-predictive-stable` 只由片段数和场景数晋升 | 出现频率没有验证未来预测准确性；这段分级也没有生产调用方 | 删除分级函数、接口、查询方法以及未接线的 meta-authority/实验振荡器；保留原始内部通道审计与检查点格式 |
| R-series 再包装同一份记忆并重复哈希 | 没有新增学习或控制职责；生产持久化已经由 V3/V4 owner 和 runtime 管理 | 删除 wrapper 与额外公开入口，保留真正的词典、议程和配对器 |
| 多次“final-refresh”脚本维护冻结身份 | 六种递增命令只服务一次历史审计，不属于代理功能 | 删除该历史脚本，使用固定 Git 提交定位旧实现 |
| 固定权重竞争场被称作类人、非脚本推理 | 权重、资格条件、候选生成与探索抑制仍由工程师设计；随机收敛不能证明类人性 | 删除/修正文档中的过度解释；本次保留活动算法，等待行为对照再决定是否替换 |
| 24 个随机预测样本被当作真实因果置信度 | 它们共享同一模型、经验和偏差，不能当作 24 次独立环境干预 | 明确其模型内测量含义，保留真实干预与未知结果边界，不调整阈值迎合目标 |
| 已提供 intervention API 就等于自主实验闭环完成 | 控制器没有调用这些接口形成完整的自主课程；示范也使用过外部带领经验 | 文档明确实验接口与已验证行为的差别，不虚报自主因果发现 |
| 可删除的审计记录决定动作输入端口 | 删除事件检索表会导致恢复崩溃；清空索引会改变相同介质的动作约束 | 从已有动作绑定和真实有序脉冲恢复端口，查询不再通过审计事件名称识别动作 |
| 两个脉冲也能恢复“条件—动作—结果”续程 | 原分支把末尾历史结果放入续程候选的输入，违反预测边界 | 删除该分支；没有独立动作脉冲的记录不产生续程候选 |
| 每个旧派生索引版本都需要一个导出常量 | 恢复只比较当前身份，旧常量没有调用方 | 删除 15 个无用途的历史版本常量及重复导出，保留既有兼容导出名称 |

删除的是退役实现及仅针对它们的回归。当前物理机制的回归仍然保留；收尾修正了
过期夹具和两处不再成立的测试预期，具体理由见验证节，没有降低资格或歧义门槛。
旧文档和原始实验结果
也没有被清除；旧源码与命令请在审查基线提交中查阅。

## 删除之后的简化

- 关闭保存只接受真实 Worker 的 `SerializedSnapshotBundleV1`。测试验证封闭被动
  窗口、关闭 R2 连续过程、落盘、关闭身体/Worker 的顺序，并实际恢复保存的 V3。
- Dashboard 的完整快照投影直接使用当前类型，去掉 `Record<string, any>` 与旧页式
  结构猜测。防修改测试改为使用真实分布式快照。
- 文件哈希测试改用当前介质文件及标准 `fileURLToPath`，避免 Windows 专用的
  `pathname.slice(1)` 在 Linux 丢失根路径。
- 构建先删除生成目录 `dist/`，防止被删除的测试和旧实现仍以陈旧 JS 继续执行。
- README 只保留当前入口、当前协议及明确的能力边界；移除互相冲突的旧状态段落。
- R2A 恢复保留已记录的动作边界，只有旧输入需要源事件补全。动作端口来自现有绑定
  与真实脉冲顺序，不再由可删除的审计索引决定。实际命令幅度仍取自原加权输入。
- 物理续程恢复只保留到最后一个真实命令；命令后的中间结果和末尾结果均不作为输入。无法识别完整条件/动作/结果边界的记录不产生候选。
- 反事实测试共享一个“只翻转物理末态”的小夹具，删除两段手工拼接的重复事件。

V3/V4 生产检查点容器、真实事件写入规则、底层物理动力学、预测器、控制场、
行动资格阈值均未改变。R2A 派生索引身份升为 V21；旧索引必须重新读取保留的物理
场，不能作为已验证缓存继续使用。删除了旧实现、历史常量和 R-series wrapper 的直接导出，这是有意的
源码 API 收缩；依赖这些退役入口的调用方应使用基线提交审计，不能无提示迁移为
当前能力。现有原始审计状态继续按原协议读写。

## 下一步的判据，而不是继续堆叠模块

先补齐两项回放所需的原始证据，并显式运行尚未执行的物理控制诊断，再讨论新机制。
缺少可复现的行为验收，继续加缓存、并行化或控制层只会更难知道失败来自经验、模型还是调度。

之后用同一个小型环境、相同公开输入与行动预算，进行以下可否证对照：

1. 空经验与学习后，冻结并评估未见条件的预测误差；再消融相关物理经验，检查能力
   是否随之消失。单独报告模型有效样本率、真实成功率与计算成本。
2. 顺序经历 A→B→A：测量学习 B 的速度、A 的保留、失效关系的纠错与保存恢复后
   的持续性，不通过重建独立冻结模型来代替连续学习。
3. 固定训练只包含孤立转移；分别从 `note=0` 和 `note=1` 追求同一个 `note=3`
   终态，检查动作次数随起点改变，并在每步得到新的真实反馈与最终观察确认。
4. 给完整系统、移除某层的系统、简单经验转移表使用相同感知和预算。如果某层
   没有改善预先约定的能力指标，下一次先删除该层；若简化模型表现更好，直接替换。

上述是建议的下一阶段验收设计，**本次未实施或声称通过**。当前最诚实的状态是：
保留了一条有部分证据的物理经验原型，删去了无法为当前目标提供作用的维护负担；
自主探索、持续学习与多步目标执行作为统一能力，仍待验证。
