# Kairos：真实探索与物理预测驱动的基础目标演示

## 已经取得的证据

这里的“思考”限定为：根据公开目标查询物理经验、比较当前条件、运行真实随机预测，由联合场选择动作，再用现实检查结果。不将它等同于人类思考或通用多层规划。

- 自主探索：从空经验开始，联合场自主选择 8 次真实动作，包括转向、观察、等待和快捷栏。每次都有真实回执和完整事件；932 帧连续，110 个事件内采样与原始帧完全一致。本次没有平移、跳跃或完成初始化的证据。
- 目标行动：载入由 128 条真实事件形成的独立冻结经验，在未用于采集的布局中，只注入指定音符盒 `note=1` 的目标。实际初始值为 0。
- 物理依据：所选交互属于经验分支；24 个有效随机预测样本全部产生目标进展，R1/R2 物理足迹和 R2A `intervention-supported` 关系来自冻结基线，不来自测试后新增事件。
- 现实验证：场选择交互，真实音符状态 0→1；随后选择观察。控制器在第 7742、7776 帧两次确认状态成立。两次动作、两条事件、12346 个连续公开帧，采样/回执/入账无失配或重复。

测试脚本只准备隔离场地、载入经验和注入最终公开谓词。目标注入后没有脚本操作音符盒，也没有给控制器动作顺序。预测支持“参与了选择”已取得证据；没有把一次成功扩大成统计泛化或因果必需性结论。

## 本轮修复与效率

- 纠正被初始区域身份覆盖的终端读出、被读出掩码改变的模拟路径，以及未实际到达终端却认定到达的问题。
- 层间投射保留实际测得的局部邻接，不把同一个输入群体拆散；映射身份改变后只从可信原事件重建，不迁移旧坐标。
- 一份不可变物理快照内，完全相同的种子/输入/读出掩码可以复用随机批结果；事件及候选证据仍分别计算。
- R1 资格探针按真正影响测量的输入复用，固定中性案例从 224 次探针降到 32 次，8.987 秒降到 1.511 秒；资格结果 SHA-256 完全相同。这不是整个实机快了六倍；两次实机总时长下降约 8.3%，仍含恢复、推演和结束保存。
- 恢复后消失的物理关系返回明确的零支持，不误抛协议错误，也不换关系、放行执行或伪造预测。

当前最终直接相关集合 44/44，通过构建；未重跑历史全量测试、旧 Formal V3 或使用 LLM/API。

## 尚未认证的范围

自动对准、多层绕障、按钮—门链、开放世界探索、所有注意力偏差场景，以及动态变化下长时间预测的实时适用性，都不在这份直接目标证据范围内。当前只在已公开、稳定场地证明了预测参与目标选择。

音符交互的匹配干预操纵的是实际 `survival/spectator` 条件；它不能替代“如何转向对准”的因果经验。转向候选的完整终端读出覆盖仍不足，不能降低到达门槛、补历史模板或硬编码正确方向来宣布通过。
