# 分区候选评分与故障证据

R9 的状态处理优化未解决变化场景下的学习积压，在线试验最终完整性失败。新候选只在比较潜在分区时计算实际使用的拟合损失和按原始窗口聚合的外部校准损失；不再为未选中的候选构造完整叶节点、残差分位数、范围和进展统计。选中结构仍使用全部原有统计，分裂候选、顺序、阈值、增益和每 16 行结构更新时机不变。

固定 R9 构建与候选在容量 32/48/192 下的 192 个合成窗口、3,072 个查询保持逐项一致。进一步从 R9 故障检查点选择“保留行数 × 目标数 × 最大输入数”最大的连续回路，在两份丢弃的私有模型中按原始窗口 ID 各复放一次其 192 个保留样本组。所得结构、样本和 168 个查询相同，耗时约 5,305 与 2,806 毫秒。被淘汰的历史不在这些私有模型中，因此它们不是实际终点模型重建，也不提供新的独立经验或实机速度证明。

前两次复杂数据诊断分别因错误使用旧版快照格式、重复原始窗口而被原有校验拒绝，日志保留。没有放开版本或去重约束；最终诊断按原始 ID 各处理一次。另有 R6 全部 150 个被动窗口的实际终点模型逐字复核。完整软件门禁 326/326，66.592 秒。首次初始化测试漏改对应运输计数造成的失败也保留，修正测试夹具后通过，没有放宽核验条件。

证据收尾同时修复：发生连接故障时保留最后接收的观测为明确的历史缓存，绝不把它冒充新末帧；仍尝试关闭活着的身体连接，已退出连接不等待回复，清理有独立的 5 秒超时。实际工作线程故障测试覆盖这些路径。末帧不可得时，停止、窗口及帧核验输出未知/不完整，不能显示关闭尾部为零。

新的试验还保存声明初始帧之前、实际已交付的原始遥测记录，包括原采集时钟和缓存锚点来源。它们单独归档，不生成学习窗口；独立核验检查它们是否完整解释首个同化计数，缺失或时钟冲突均不能通过。运行中的全部运输顺序和独立递归重放仍不是当前核验器已经证明的能力。

事前登记仍为同一原始 smoke 起点的在线/冻结 32 决策、180 秒。第一组必须完整性通过后才运行第二组；任何故障、超时、拒绝和未知项均保留。长期学习、A→B→A 保持、因果前提链和长期保留种子验收尚未取得。
