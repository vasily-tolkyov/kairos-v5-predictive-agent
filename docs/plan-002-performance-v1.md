# PLAN-002 · 性能优化（语义保持）

本批只实现不会改变物理协议或结果语义的性能基础：

- 用内存修订计数标识只读介质快照，避免对完整介质反复计算哈希；写入和恢复时递增修订并使缓存失效。
- 提供显式的精确批量预测入口，复用现有 seed 级 Worker；默认仍为串行，调用者必须明确给出并行度。
- 保持结果按 seed 输入顺序返回，Worker 失败原样抛出，不重试、不降级、不丢弃结果。
- 仅缓存只读快照和 PredictionClone；查询和预测不得改变生产介质。

本批不修改冻结物理常数、R1/R2/R2A 证据门、恢复规律、动作选择或运行时调度。完整基准和全量回归按项目负责人要求留到下一轮评估后执行。

## 接口约束

`DistributedHierarchicalPhysicalMemoryV1.predictCandidateParallel` 是可选的异步入口；`parallelism=1` 与既有同步 `predictCandidate` 使用同一物理请求，结果必须逐字段一致。并行只切分独立随机种子，不能切分单条轨迹、改变随机种子或共享可变介质。

修订计数是进程内缓存身份，不写入快照，不构成新的长期状态。缓存只在同一实例、同一修订内有效；任何真实写入、恢复或时间推进都使其失效。

## 验收

- 同一快照串行与显式并行批量结果逐字节一致且顺序稳定。
- 写入或恢复后不会复用旧缓存。
- 预测/性能接口前后生产快照哈希不变。
- 无新增依赖、无网络、无 Minecraft 或 Formal 运行。
