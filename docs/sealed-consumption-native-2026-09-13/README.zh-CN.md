# 原始证据复用与表面匹配开销

R8 在线 0/32、冻结 12/32，仍没有目标完成。新的候选减少原始数据重复处理，保留原有动作、预测和学习语义。

只有完整校验并递归冻结的普通原始数据可以复用摘要。可变副本继续全量散列，相同 ID 不表示相同证据；浅冻结外壳、访问器、自定义序列化和环引用不会取得缓存资格。模型仍校验实际状态所有权，序列化副本不能伪造真实轨迹。缓存使用弱引用，不保留已退出的原始窗口。

世界表面匹配采用当前记忆位置的临时单位格索引，检索全部 27 个相邻格。原有最大匹配半径为 0.8，因此被排除的有限位置不可能通过原有距离要求；没有最近 k 项裁剪、阈值改变或外部地图。候选按原有插入顺序处理，保留平局、歧义、淘汰和可见性语义；无效数值走原有全量候选路径。直接三维距离及颜色累加保留原有计算顺序。

固定 R8 构建与候选的 720 个合成世界快照和新颖度查询相同。R8 的 161 个已归档被动窗口提供 1,134 个包含共享端点的轨迹状态比较、161 个完整世界快照比较，均相同；这个数字不是独立样本数。两端共 1,024 个保留帧封装摘要先单独核验，再归一化各私有实例随机产生的所有者标识。首个性能报告仅归一化标识字段、未处理嵌入摘要，因此其两个 liveDigest 不能直接比较；原报告保留，后续独立差分明确纠正该诊断问题。
