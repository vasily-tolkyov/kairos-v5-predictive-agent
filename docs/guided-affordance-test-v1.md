# Guided affordance test V1

This test separates teaching from reasoning.

## Teaching phase

- A neutral micro-world supplies 128 completed public events from eight training layouts.
- A guide chooses primitive look, interact and observe actions and repeats them under contrasting public conditions.
- Every outcome is produced by the micro-world and enters the ordinary `PhysicalMemory.observe` path.
- The guide never writes an anchor, R2 category, R2A factor, relation or expected result.

## Reasoning phase

- The frozen training memory is restored into two independent cases with unseen layout IDs.
- Each case creates a new transient control field and receives only the grounded goal that the indicator becomes active.
- No action sequence or intermediate target is supplied.
- The body exposes only currently available primitive actions. Interaction appears only while the control object is in the crosshair.
- Success requires physical effect recall, R2A condition comparison, real PredictionClone rollouts, a field-selected action, and two observations separated by five ticks.

This validates a controlled recombination of learned primitives. It does not establish Minecraft generality or autonomous discovery of an interaction primitive.
