新读出使用同一学习介质中的连续命名空间，49 个输入系数包括固定投影与历史激活；旧参数和旧无时钟经验保持原语义。现阶段只认证真实开始的整窗末态及实测一步间隔。私有预演不具有多步支持证书，尚缺有界状态不确定性传播和动作释放后返回时间建模，不能据此验收 B。
