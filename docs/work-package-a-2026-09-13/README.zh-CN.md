已修改的行为：

- 上下文树维护参与真实响应分区的类别域。未知类别不能落入“非 A”后直接继承 B 的支持；新类别需要自身实际更新前校准。缺失相关字段、越界数值、无效区间及点/区间冲突也不能绕过局部或回归支持检查。无关新特征仍可泛化，连续插值仍可用。
- `MotorReceiptV1` 随动作窗口保存请求、按下、释放时钟及帧范围。物理 tick、死亡补测帧和单调时钟分开；catch-up、死亡、超时、断线、关闭均释放控制。学习使用有收据的实际按压时长，保留原始请求和事件字节。零物理间隔只记已处理事件身份，不增加学习写入。
- 同进程身体在动作前重新绑定、消费较早的真实被动窗口，再通过同一介质生成只读预测；支持撤销时拒绝执行旧计划。完整感觉帧摘要防止同序号的不同画面借用证据。复传的同 ID 不同内容和来自未来的被动窗口均拒绝。
- 首批 actor 的异步 worker 会排除过期预测，但还不能产生新的执行前预测；其 8 次过期记录仍保留。当前 actor 改为 worker 捕获完整当前帧并给出一次性 token，主线程消费此前真实窗口后只读预测；worker 核对同一帧后立即执行，帧变更就拒绝，不停住世界且没有内部重试。取消、过期、错误 token 和故障不能重放动作或丢弃已接收的被动证据。详见 [异步协议与回归](worker-fresh/PROTOCOL.zh-CN.md)。
- 原搜索分支与真正执行前的预测分别登记。`WorkerActionStartReceiptV1` 诊断、决策 token 和实际事件首帧摘要可独立核对；接受帧绑定仍不等于动作成功。

首批封存的实机记录为 **21 次装置校准动作与 8 次自主选择动作**。装置经验没有加入自主模型。原生闭环仅运行了 8 个决策预算，不能证明保持、迁移、多阶段规划或长期有界资源。该短跑的 RSS 采样为约 408–555 MB；单次循环约 403–4503 ms，包含动作等待与日志开销，不能用来声称预测满足实时截止时间。

当前异步运行另有 **4 次自主选择动作及 4 次拒绝**，固定 8 决策/120 秒上限，实际约 17.339 秒。总体执行比例为 50%，执行动作中的开始帧匹配为 100%；这两个分母不得混用。四次执行前查询虽然都发生在正确的开始帧，但其受支持字段与可比较字段均为 0，不能据此计算预测正确率或区间覆盖率，更不能宣称完成任务。准备到核验耗时约 12.98–63.81 ms，包含被动窗口处理、预测和通信；RSS 采样约 441–584 MB，均不是长期资源或最坏单次预测预算证明。新停止世界、完整首帧及恢复审计已通过。采集启动边界有 **31→32 的一个未记录间隔**，没有补造帧；其后动作间等待的 27 个间隔均由实际被动窗口覆盖，不能称整个启动过程连续无缺口。

新增时长校准的 6 次动作也全部通过。两批合计 **27 次装置校准动作、12 次自主选择动作、4 次拒绝**；两次独立自主短跑各有 21 次学习写入，模型未合并。
