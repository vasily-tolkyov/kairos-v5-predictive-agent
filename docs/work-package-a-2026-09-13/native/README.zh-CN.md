# 工作包 A 原生装置证据

本目录保存本轮新执行的 4 个隔离装置校准：基线运动 6 次、装置候选运动 6 次、实体可见/遮挡与攻击 1 次、感觉与持物使用 2 次，共 15 次评估器选择的真实动作，0 次自主任务试验、0 次学习写入。全部服务端已停止。

两组运动均按下 4 ticks，交错无附加负载/230 ms 主机负载，实际控制计数全部为 4；候选的嵌入收据通过独立审核。实体可见像素 65、遮挡后 0，服务器确认攻击前后健康 20→19.06。持物使用实际 40 ticks/2 个物理秒，食物 5→9、持有数量 3→2，食物值由独立服务端回执确认。

`summary.json` 固定每个结果的 actor 归属。`actors/*.json` 记录每个编译 src 文件的摘要；相应 `.tar.gz` 仅封装原始 src 字节和 ESM package.json，不含依赖。基线和中间装置候选是两套不同 actor；中间候选先于最终集成的同步动作起始标记，不得将这些结果归给最终 actor。

原始结果、窗口、画面、旁路记录、服务端日志和启动/审核记录均保持原字节。文件里的原绝对路径是历史元数据；重放时为命令显式传入本地解包后的 actor 路径和运行时路径，不改原件。固定依赖安装应使用项目原 package-lock.json；actor 可解包到项目下以使用该处的 node_modules。harness 支持显式 --build。

原始模型对/frame 19/停止世界包仍不可读取，此包没有替代它们。此处不是保持、陌生世界学习、生存或因果多阶段能力验收。为保持包体积紧凑，没有复制可写世界和游戏/Java 二进制；独立服务端回执和原始观测仍完整保留。runtime-provenance 保留 Java 初次元数据尺寸断言失败：实物少 44 bytes，但 SHA256 与官方值精确一致、gzip 校验通过后才执行。

`MANIFEST.json` 对本目录除清单自身外的每个文件记录相对路径、字节数和 SHA256。
