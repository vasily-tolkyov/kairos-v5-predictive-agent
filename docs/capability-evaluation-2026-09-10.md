# Kairos 能力评估与本轮修复结果

本轮完成了可复现的能力测试、缺陷修复和复测，**最终能力验收未通过**。
192 次自主动作选择形成 384 条 R1 经验、192 条 R2 过程；12 个可达任务中
10 个得到后续公开观察确认，但没有一个通过预测驱动的规划验收。
不能把这些探索中的成功称为持续学习或多阶段规划已经完成。

代码只在本地处理，未向 GitHub 推送。审查基线是清理后的
`330e0eabf496d361853bfac1edade0b0ccd58e53`；此前远端基线是
`7fe4157dcac57daf9febf5f0d449ea938a081249`。

## 测试了什么

环境使用匿名执行器与公开布尔状态。真正的生产记忆、数值物理介质、控制器和
目标求值器负责学习、查询、选择与完成判定。环境没有向它们提供任务解法、
中间目标、因素解释或预设动作序列。

同一记忆和控制器经历 A→B→A，每阶段自主选择 64 次动作。B 交换两个执行器
的效果，保留另一个执行器的规律。训练中的独立遭遇从随机公开状态开始；重置
打断连续性。每次动作前后都保存完整真实的合成环境观察，包含不发生改变的结果。
192 次选择包含 134 次执行器动作和 58 次观察动作，不是 192 次不同实验。

每阶段冻结学习，给出五个留出任务：从距离相同终态一、二、三步的起点执行目标、
执行未变化的关系、处理不可达目标。动作预算为五次，每步必须重新接受反馈，
结束需经过五个观察 tick 的持续确认。评估期间 15 个任务均未写入训练记忆。
没有由外部脚本注册因果干预配对。

规划判据要求执行节点来自合格物理分支，不能来自探索节点；生产执行资格仍要求
至少 8 个有效样本和至少 0.75 的样本进展率，预测使用 24 个内部模拟种子。
这些模拟种子不等于 24 次环境实验。所有成功案例的实际执行均来自探索，依赖数为零。

为区分样本不足与表示缺陷，另跑了已有的均衡两步生产集成：按真实事件协议构造
四组合成经验，
每组八次、跨四个上下文，完整进入 R1/R2/R2A。清理后基线、修复各中间版本和

该诊断由测试显式注册配对，用来检查学习机制，不是自主实验成功的证据。
它在进入目标执行前已经失败，不能把后续未运行的阶段算作通过。

## 实施并保留的修复

1. **保留无直接目标动作的真实负结果。** 感知编码曾只为直接目标保留已学通道，
   导致自身或远端对象的未改变结果丢失。现在按同一动作已有的感知通道保留实际值，
   同时删除重复末态补录；无关背景和未见通道不会被编造成结果。
2. **按动作和对象计算探索新奇度。** 修复尝试一个对象后同时压低另一未尝试对象
   新奇度的问题。公平覆盖更一致，但它还不是信息收益驱动的实验设计。
3. **修复达标后的终态确认。** 最后一个动作耗尽预算仍允许真实新观察确认；目标
   已满足时停止继续处理旧目标的动作和推理。短暂达标后撤销仍会失败。
4. **删除不可能有效的整理工作。** 同动作样本还不可能形成两组八成员对照时，
   跳过昂贵探测；每条真实经验仍立即沉积。
5. **解除整理的循环前提。** 不再要求两个结果已能稳定预测，才允许学习它们的
   条件差异。整理只重放已有重复观察的物理差异，不授予关系等级或执行资格。
   派生索引在查询时测量，删除每批经验后的重复全量发现。
6. **固定相同物理测量的校准输入。** 末态校准种子不再依赖无关候选位置和上下文。
   派生索引身份更新为 V22，旧索引重新读取；没有凭空补全旧经验中遗漏的观察。
7. **删除必定丢弃的备用探测。** 已成功校准的候选不再执行无用备用测量，保留
   原候选编号、种子和完整读出范围。优化前后的完整 G5 物理快照逐项一致。

V3/V4 容器、底层物理规律、真实写入边界、8 成员/4 上下文的证据要求和执行门槛
均未降低。完整 A→B→A 跑在第 7 项纯删除优化之前；随后用完整快照等价比较和
最终两步集成检查该删除，并在交付树上重新构建。另将无外部调用的必要条件辅助
函数保留为模块内部函数，没有新增公共 API。

一次额外消融尝试删除与最后原子相同的关闭末态脉冲。局部五项测试通过，但均衡
两步任务仍以同一原因失败，没有支持它修复核心表示问题的证据；该改动已撤回。
实验补丁与失败日志保存在证据包，不进入交付代码。

## 性能与回归

早期在线整理版本在 1,500 秒预算内只记录到 48 次探索动作，未完成请求的
128 次。删除不必要的同步发现后，最终功能版本首次 64 次动作及 128 次写入约
6.3 秒完成。然而随后首次完整快照/索引测量仍需约 377.8 秒，后两次为 437.5
和 401.4 秒；完整 A→B→A 用时约 21.1 分钟。不能把写入阶段变快称为全部
推理已经实时化，索引测量仍是明显瓶颈。这些时间来自本次机器，不是严格基准比率。

相关回归分三批运行：34 + 26 + 93 = **153 项通过，0 失败，0 跳过**，覆盖
31 个测试文件，包括感知负结果、对象探索、持续确认、物理差异、反例降级、
审计删除、物理消融、查询只读、检查点、动作边界及控制接线。
这不包含另行失败的均衡两步能力验收，也不是整个仓库测试套件全部通过。
最终构建、评估脚本语法和补丁空白检查通过。

Node.js 为 24.19.0，TypeScript 为 5.9.3。测试命令、输入范围、失败状态和
原始记录位置见 `capability-validation-2026-09-10.json`。证据包包含测试日志、
两个 A→B→A 结果、阶段物理快照、最终训练原始事件及撤回实验，不包含生成的
编译副本或依赖。

## 剩余缺陷及下一道修复关卡

| 优先级 | 缺陷与要挑战的假设 | 下一项具体工作与通过条件 |
| --- | --- | --- |
| P0 | 重复沉积和全局末态吸引子足以产生条件预测，目前未获支持 | 在均衡两结果数据上隔离感知、投射和读出，比较当前层级与更小的物理经验模型；只用当前条件加动作预测两种结果。必须保留负结果、经物理消融失能、删除审计标签不改输出，并使现有真实两步诊断通过 |
| P1 | 公平轮换和对象新奇度足以产生有用知识，目前仅证明覆盖 | 在 P0 通过后，让代理选择有可区分预测的实际干预；用冻结未学习对照衡量之后的预测误差与执行增益，不能由测试脚本替代理注册成功实验 |
| P2 | 增加经验条数意味着持续学习，目前没有获得/保留/纠错证据 | 同一模型接受变化规律；增加到满足对照要求的训练量，检查错误预测下降、旧错误不再主导、未变规律保留，随后跨多个环境种子重跑 A→B→A |
| P3 | 单步模式可自然组合成多步计划，目前未发生 | 只给终态，在不同起点形成不同长度的预测依赖；每步经新观察重规划，可达目标都以预测分支执行，预算边缘和不可达目标不误报 |

本轮不再通过增加缓存、调度层或放宽等级掩盖 P0。若最小受控任务仍无法形成
正确的条件预测，应替换失败的表示或层级，而不是继续围绕它增加规则补丁。

Minecraft 原始证据、服务端、世界和冻结现场经验不在当前工作区。本轮运行的是
生产数值物理介质加合成环境，没有新的 Minecraft、实体物理介质或类人认知验证。
