# Three-stage development status — 2026-09-10

This source update is not a successful three-stage qualification or a release
of a generally capable Minecraft planner.

## Included engineering changes

- Sparse, actually reached physical readouts feed bounded short-chain prediction;
  each seed keeps its own lineage. Missing future properties remain unknown.
- Control dependencies and the root goal persist across real actions. A changed
  observation/physical version invalidates old conditions and unexecuted suffixes.
- Exact read-only prediction reuse, topology-preserving input projection,
  metadata point reads and linear snapshot paging reduce measured duplication.
- Seed workers receive one encoded immutable snapshot; their decoded physical
  objects and transient activations remain independent.
- The latest repair removes an entire R2 snapshot export used only to count the
  pending atoms. One recent continuation result can be reused only when the
  complete physical version, observation, pattern and precise action agree.
  It is not an action-selection rule or a persistent memory.

## Real experiment status

The test teaches isolated state transitions, never the complete solution, then
injects only the final public goal. Case A starts at `note=0`, targets `note=3`,
and therefore needs three successful state-changing interactions. Planned case B
starts at `note=1` with the same target to distinguish goal-directed completion
from always issuing three clicks. These are state-dependency tasks with one
action type, not mixed-action navigation or button–door planning.

After the initial failures, an explicitly recorded balanced real rehearsal added
isolated examples of all three transitions. The current independent frozen
baseline contains 384 R1 events, 192 R2 events and three supported relations.
Eight positions represented four distinct public marker geometries; positions
are not reported as eight independent geometry classes. Reassessment reused
existing matched-pair results; it was not twelve newly run intervention probes.

The latest real attempt, A004, recorded 17,081 continuous public frames and two
physical-support-backed interactions:

| Real change | Start frame | End frame | Effective progressing samples |
| --- | ---: | ---: | ---: |
| `0 → 1` | 5264 | 5304 | 24/24 |
| `1 → 2` | 12618 | 12658 | 24/24 |

At the third step the current condition matched, but the production predictor
returned `distributed-R1-attractor-inactive` and zero valid samples. The run was
stopped without substituting an exploratory click. No `goal-verified` result,
third action or successful final checkpoint was fabricated. All four failed
attempts remain in local evidence. Case B has not run.

One repeated continuation identity at frame 5308 occurred 71 times and consumed
approximately 59.55 seconds. The latest exact-query repair addresses that
duplication without changing recovery, physical thresholds, seed counts or the
task. Its direct tests pass; the before/after real-memory benchmark was
interrupted and the new code has **not** been qualified in Minecraft.

train a model, access old Formal V3, or start another Minecraft attempt.
