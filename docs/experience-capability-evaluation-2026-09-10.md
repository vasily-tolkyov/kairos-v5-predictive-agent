# Kairos 经验学习核心：能力验收与理论重构

2026-09-10。本轮基于本地修改版 `87e28e9` 继续，交付 0.3.0。没有向 GitHub 推送。

## 结论与证据范围

**固定感知接口的仿真原型已取得主动探索、持续学习和多阶段目标执行的联合成功证据。** 三个随机种子、三次连续阶段（A→B→A）共完成 252/252 个目标；每一步均由学习模型预测、真实仿真反馈复核，最终状态经过后续观测确认。训练不提供目标、子目标或完整解法。

这份结论对应重构后的 `ExperienceMedium` 与 `ExperienceAgent`。旧晶格 G5 仍然失败，未被修改为通过。新核心是软件中的速率神经元介质，不是实体硬件，也不是人类认知等价性证明。没有新的 Minecraft 实测。

## 从第一性原理删除的假设

首先检验旧模型，而不是把既有层级当作目标本身：

1. 去掉重复注入的行动前状态后，旧模型由两个稳定分支、零关系进展到四个稳定分支、四个关系。它确实存在输入和结果混叠。
2. 去掉 R1 的额外无条件吸引子要求，目标经验可以被召回。但八次匹配干预的完整条件选择率仍然都是零。
3. 直接测量发现，不输入行动也能产生接近的条件—结果场。终态自激稳定不能替代“当前条件下执行某动作”的前向预测。
4. 临时门控和移除集合共振也没有修复关键能力；相关实验被撤回，补丁及原始输出保留作失败对照。

因此，本轮从当前公开入口和默认执行路径移除了三层晶格、吸引子资格阶梯、外部干预登记和独立竞争控制场的依赖。旧实现保留为显式 legacy 比较及旧存档读取来源，当前 API 不再导出它们。

## 新理论与最小实现

保留的是可检验的闭环：**观测 → 自主选择动作 → 执行 → 结果 → 预测误差更新 → 用更新后的模型规划**。

感知、动作和结果使用不同的神经元群。动作选择一个电机输入通道；没有动作输入就没有可执行预测。连接权重只由完整、实际执行的观测窗口修改，结果不会作为预测输入注入。

隐藏单元使用膜电位松弛 `du/dt = drive − u` 和 `tanh` 响应。直接连接与隐藏连接共同预测各感知通道实际见过的值。误差通过梯度与反向传播更新连接；每个动作保留最多 64 个回放样本。所有连接都是从经验学习的，没有预填的保持、切换、开门、设定条件或目标路径规则。

模型输出是未校准的读出分数。执行要求膜电位收敛、至少 16 次实际观测、更新前测得的近期整状态预测准确率不低于 0.9、读出胜出差不低于 0.8。这些是公开的工程门槛，不是因果证明或成功概率。

探索由经验覆盖不足和预测误差驱动；规划以同一个前向模型作有限广度优先搜索，默认最多六步、512 个展开节点。每次只执行第一步，收到反馈后重新搜索。相对目标的基准固定在接收目标时，避免“增加 3”在每次重规划时向后移动。目标确认需要至少五个后续观测序号，允许预算用完后继续观测。

## 修复与迭代结果

| 发现的缺陷 | 已执行处理 | 结果 |
| --- | --- | --- |
| 旧条件场绕过行动，结果混叠 | 更换预测核心，分开输入/输出群，由实际结果误差学习连接 | 无行动输入不产生可执行预测 |
| 新模型早期只通过目标，仍有未见状态错误 | 增加穷举复核，保留失败记录；加入可学习直接连接并继续自主获取经验 | 512/1,024 次经验的失败记录保留；4,096 次/阶段达到全域正确 |
| 环境变化后旧预测仍可误导动作 | 每步实际反馈重规划；持续更新，同一记忆不重置 | 六次机制切换中冻结学习失败，继续学习后全部目标成功 |
| 只复习旧任务不能证明避免遗忘 | 增加另一动作机制的学习测试，旧动作不再练习 | 新旧两个非线性响应均保持正确 |
| 只验证布尔目标 | 增加数值 0→1→2→3 与相对增量目标 | 学习孤立一步经历后自动组合三步；剩余计划长度 3→2→1 |
| 预测或单次终态被误认为完成 | 冻结查询、读取真实后续观测；测试短暂终态和停滞观测 | 无虚构完成、无查询训练 |
| 旧启动入口仍指向失败架构 | 更换 `src/prototype.ts`、`npm start` 和能力评估入口，接入现有身体接口 | 新默认路径可运行；legacy 命令显式保留 |

完整能力测试用了种子 41、73、109；每个种子重新随机化传感器名称和动作映射，再在同一记忆上依次经历 A、B、A。B 交换两个动作机制。学习器只看到公开观测和执行反馈，不接收阶段标签。

每次训练都是独立起点的一次自主动作，训练明确排除三个阶段状态均为假的初始组合。评估则包括这些起点、不同干扰变量、部分完成的起点和组合终态。没有训练整条目标轨迹。

## 因果与必要性对照

- 三次未学习的冷启动均不能规划成功。
- 六次机制改变后，冻结学习的旧模型都耗尽动作预算；随后继续学习的模型全部通过。
- 九份模型清除学习连接后，目标均返回未知。
- 九份模型去掉电机输入后，均不能给出可执行预测。
- 评估过程中学习关闭；模型存档前后哈希一致。恢复后的下一次学习也保留相同回放随机状态和参数结果。
- 非线性 XOR→XNOR 的机制切换、另一动作学习后的无复习保留、数值多阶段控制、反馈断帧、非真实来源、重复事件冲突、损坏参数和迟延确认均有自动回归。最终 13/13 项回归通过，完整能力验收运行约 161 秒。

这些对照证明本测试中的成功依赖实际学习到的连接与行动输入。它们不把预测正确率升级为普遍的因果识别能力。

## 复现与交付

```sh
npm ci --ignore-scripts
npm run test:experience
npm run test:capabilities -- --output ./evidence/experience-capabilities
```

能力命令默认就是本轮的完整验收配置；失败返回非零状态。交付包保留原始训练事件、九份检查点、逐目标及逐动作结果、回归输出、失败迭代记录和文件校验和。报告旁的 `experience-capability-results-2026-09-10.json` 是机器可读摘要；逐动作原始结果保留在证据包。

新存档版本 `KairosExperienceMediumV1` 与旧晶格 V3/V4 分离，不自动转换旧存档。`npm start -- --help` 提供新身体入口；需要事先运行并配置 Minecraft 服务。

## 仍未得到证据的能力

当前模型使用固定感知通道和有限已见值集合。连续空间外推、对象出现/消失及遮挡、开放类别扩展、新动作发现、更长时间跨度的探索和 Minecraft 现场运行仍未验证。遇到未见值或感知结构时返回未知，不能把本次有限域成功外推到这些场景。

网络容量、探索驱动力和回放容量仍是工程设计；反向传播并不证明与人脑相同。事件身份审计随运行增长，回放本身有界。下一轮需要面向这些独立风险设计新证据，而不是重复扩大本轮已通过的有限域测试。
