# 能力验收与修复计划

基线是本地清理后的 `330e0eabf496d361853bfac1edade0b0ccd58e53`。
本轮只修改本地代码，未向 GitHub 提交。Minecraft 原始回放、世界和服务端仍缺失，
因此这里的行为结果属于合成环境中的生产数值物理记忆，不能称作实机结果。

## 验收方法

`scripts/evaluate-capabilities.mjs` 使用真正的记忆与控制器。环境提供公开观察、
可执行动作及其后果，不提供子目标、动作顺序、因素名称或预测答案。探索阶段每次
从独立的随机公开状态开始；每个执行动作前有一个真实被动观察窗口，闭合为两个
原子的 R2 经验。每条观察保留连续帧，重置明确打断连续性。

同一记忆和控制器依次学习 A、B、A。B 交换两个执行器的效果，保留第三个执行器
的规律。每阶段之后冻结学习，分别从距离相同终态一、二、三步的起点执行目标，
再测不变关系和不可达目标。每步接受新观察，最终必须由后续公开观察确认。

判据分开记录：覆盖动作不等于有效探索；经验条数不等于学习；终态偶然达成不等于
预测驱动的规划；内部 24 个模拟种子不等于 24 次真实环境实验。完整通过要求
每阶段四个可达任务都由物理分支执行、不可达任务不误报、评估不写入训练经验。

## 已定位并实施的修复

| 缺陷 | 处理 | 验证方式 |
| --- | --- | --- |
| 无直接目标的动作漏掉未变化的已知结果，包括自身和远端对象 | 用该动作已经学到的感知通道保留当前实际值；删除重复的末态补录 | 新回归在旧编码上得到 `undefined`，修复后正确读出 `false`；无关背景仍不进入结果 |
| 同一个动作作用于不同对象，共享一次使用抑制 | 探索窗口和使用抑制统一以动作加公开目标标识 | 旧代码把未尝试目标的新奇度降至 0.5；修复后保持 1，并实际访问两个目标 |
| 预算最后一步已经达标，却与“未知结束”竞争；达标后还继续推理旧目标 | 达标后只进行终态确认；动作预算耗尽仍可等待真实新观察 | 持续达标和短暂达标后撤销两项回归；均在未训练控制路径复现原缺陷 |
| 样本不可能构成对照时仍进行大量探测 | 先检查形成两个八成员同动作分支的必要条件；全部经验仍立即写入 | 16 条不同动作经验全部沉积，避免构建无用探测基底 |
| 整理要求两个分支已经预测稳定，阻断有差异经验的学习 | 整理只重放重复实际观察到的条件与结果；正式分支和执行资格仍单独经物理测量 | 真实两步任务、2×2 对照、标签删除、物理消融、反例降级回归；不将重放资格当成规划成功 |
| 相同末态的校准种子受无关条件和候选列表位置影响 | 校准种子仅由实际测量输入决定；复用同一不可变基底上的相同测量 | 当前派生索引更新为 V22；旧索引重新读取，不重写历史经验 |
| 已成功校准的分支仍执行随后必定丢弃的备用探测 | 只跳过无用工作，保留原候选编号、随机种子和完整读出范围 | 对比优化前后完整物理快照，而非只比通过数 |

8 个成员、4 个场景、24 个预测种子、最低有效样本和目标进展门槛均未降低。
V3/V4 检查点容器未改。旧经验中已经遗漏的感知通道不会由本次恢复凭空补齐，
需要新的真实观察。V22 会重建旧派生索引，可能增加首次恢复时间。

## 仍需通过的能力关卡

1. **物理分支区分。** 最新真实两步集成在配对对照处仍拒绝，不能给它补一个成功
   标签。必须在相同感知和动作下，证实成功与失败结果都能稳定区分，且实时
   条件加动作能到达正确分支；只增加快照中的模式数不算修复。
2. **探索产生可用知识。** 当前公平轮换和对象新奇度仍不足以证明主动选择有信息
   价值的实验。需要将预测分歧、真实干预机会和之后误差的下降接到同一行为闭环，
   同时用无学习对照排除碰巧达标。不能把外部脚本注册干预冒充代理自主实验。
3. **持续学习的获得、保留和纠错。** A→B→A 必须在同一经验系统中提高适应后的
   预测与执行能力，保留未变关系。累计写入数、保存恢复成功和内部等级都不是
   这些能力的替代指标。
4. **多阶段规划。** 同一终态从不同起点需要不同长度的预测执行；每步重新接受
   反馈。没有有效模型时如实报告探索或未知，不把探索轨迹事后解释成计划。

若上述行为关卡继续失败，下一项决策应是比较更小的经验模型并考虑替换 R1/R2/R2A
强制层级，而不是继续增加调度、缓存或新的等级。当前测试不会把“类人持续自主
学习”判定为完成；详见 [完整评估与复测结果](capability-evaluation-2026-09-10.md)。
